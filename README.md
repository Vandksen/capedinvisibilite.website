# capedinvisibilite.fr

Site de présentation de **Cape d'invisibilité**, outil gratuit (licence MIT) de pseudonymisation 100 % locale de fichiers Word, Excel et FEC, publié par STRUCTURRE avec GitHub Pages (domaine dans `CNAME`).

## Fichiers

- `index.html` : présentation et FAQ
- `installation.html` : guide d'installation et journal des versions
- `mentions-legales.html` : mentions légales et limites de la pseudonymisation (page non indexée)
- `telechargements/` : archives PC et Mac
- `assets/` : images et logo

## À chaque nouvelle version

- remplacer les archives dans `telechargements/` et les liens de `installation.html` ;
- mettre à jour la taille des archives dans `installation.html` ;
- mettre à jour le numéro de version : badge « Bêta · v… » (en-tête et pied des 3 pages), FAQ de `index.html`, journal des mises à jour ;
- vérifier que le nom du titulaire dans le `LICENSE` des archives est identique à celui des mentions légales.
