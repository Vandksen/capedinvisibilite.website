Installation · En bêta

Revêtez la cape
en sept étapes.

Aucune compétence technique n'est nécessaire. Suivez les étapes dans l'ordre : les trois premières ne se font qu'une seule fois.

1

Une seule fois

Installer Python

Python est le programme gratuit qui fait fonctionner l'application. Il faut la version 3.11 ou plus récente.

Sur PC
  1. Ouvrez python.org/downloads.
  2. Cliquez sur le bouton jaune de téléchargement.
  3. Ouvrez le fichier téléchargé, puis cliquez sur Install Now.
Sur Mac
  1. Ouvrez python.org/downloads/macos.
  2. Téléchargez la dernière version stable, au format .pkg.
  3. Ouvrez le fichier téléchargé et suivez l'assistant jusqu'au bout.
Vous devez voirUn message confirmant que l'installation de Python a réussi.
2

Une seule fois

Récupérer l'application

L'application tient dans un dossier que vous gardez sur votre ordinateur.

Sur PC Télécharger pour PC Archive ZIP · 46 Ko
  1. Dans vos téléchargements, faites un clic droit sur l'archive, puis Extraire tout.
  2. Placez le dossier cape-d-invisibilite à son emplacement définitif, par exemple dans Documents.
Sur Mac Télécharger pour Mac Archive ZIP · 46 Ko
  1. Dans vos téléchargements, double-cliquez sur l'archive pour la décompresser.
  2. Placez le dossier cape-d-invisibilite à son emplacement définitif, par exemple dans Documents.
Vous devez voirUn dossier cape-d-invisibilite qui contient les fichiers d'installation.
AttentionNe déplacez plus ce dossier après l'étape 3. Sinon, l'application ne se lancera plus et il faudra refaire l'installation.
3

Une seule fois

Installer l'application

Cette étape télécharge les composants nécessaires. C'est la seule qui utilise Internet, et aucun de vos fichiers n'est concerné.

Sur PC
  1. Dans le dossier, double-cliquez sur installer.bat.
Si Windows bloque le fichier
  1. Si Windows affiche l'écran bleu « Windows a protégé votre ordinateur », ne cliquez pas sur Ne pas exécuter.
  2. Cliquez sur le lien Informations complémentaires, juste sous le texte.
  3. Vérifiez que l'application indiquée est bien installer.bat, puis cliquez sur Exécuter quand même.
  1. Attendez sans fermer la fenêtre.
Sur Mac
  1. Dans le dossier, double-cliquez sur installer.command.
Si le Mac bloque le fichier
  1. Si le Mac affiche « Élément non ouvert », cliquez sur Terminé, surtout pas sur Placer dans la corbeille.
  2. Ouvrez Réglages Système, puis Confidentialité et sécurité.
  3. Descendez jusqu'à la section Sécurité, puis cliquez sur Ouvrir quand même en face de installer.command.
  4. Confirmez avec votre mot de passe ou Touch ID.
  1. Attendez sans fermer la fenêtre.
Vous devez voirLe message « Installation terminée ». Vous pouvez alors fermer la fenêtre.

À chaque utilisation

Lancer l'application

L'application s'ouvre dans votre navigateur, mais elle fonctionne entièrement sur votre poste.

Sur PC
  1. Double-cliquez sur Lancer Cape d'invisibilite.bat.
Si Windows bloque le fichier
  1. Si Windows affiche l'écran bleu « Windows a protégé votre ordinateur », ne cliquez pas sur Ne pas exécuter.
  2. Cliquez sur le lien Informations complémentaires, juste sous le texte.
  3. Vérifiez que l'application indiquée est bien Lancer Cape d'invisibilite.bat, puis cliquez sur Exécuter quand même.
  1. Laissez ouverte la fenêtre qui apparaît.
Sur Mac
  1. Double-cliquez sur Lancer Cape d'invisibilite.command.
Si le Mac bloque le fichier
  1. Si le Mac affiche « Élément non ouvert », cliquez sur Terminé, surtout pas sur Placer dans la corbeille.
  2. Ouvrez Réglages Système, puis Confidentialité et sécurité.
  3. Descendez jusqu'à la section Sécurité, puis cliquez sur Ouvrir quand même en face de Lancer Cape d'invisibilite.command.
  4. Confirmez avec votre mot de passe ou Touch ID.
  1. Laissez ouverte la fenêtre qui apparaît.
Sur PC et sur MacCe blocage est normal : Windows et Apple ne reconnaissent pas encore l'éditeur de ces fichiers. Il n'apparaît en principe qu'à la première ouverture de chaque fichier.
Vous devez voirVotre navigateur s'ouvre sur l'adresse http://127.0.0.1:5055, avec les parties « Pseudonymiser » et « Rétablir les vraies valeurs ».
Pour arrêterFermez la fenêtre laissée ouverte. Pour réutiliser l'application, reprenez à cette étape.
5

À chaque utilisation

Pseudonymiser vos fichiers

L'application remplace les noms et les numéros par des codes, sans toucher aux montants ni aux dates. Avec une même table, une valeur reçoit le même code dans tous les fichiers, même ajoutés plus tard.

  1. Dans la partie « Pseudonymiser », choisissez un mot de passe si vous voulez chiffrer la table de correspondance. Sans mot de passe, elle est un classeur Excel en clair, que vous pouvez ouvrir pour contrôler ce qui a été masqué. Le bouton Afficher permet de vérifier votre saisie.
  2. Pour compléter une table déjà créée, déposez-la d'abord dans la zone « Table existante » (avec son mot de passe si elle est chiffrée). Sinon, laissez cette zone vide : une nouvelle table est créée.
  3. Déposez un ou plusieurs fichiers dans la zone prévue : Word (.docx), Excel (.xlsx) ou FEC (.txt). Vous pouvez mélanger les formats, et déposer les FEC de plusieurs sociétés ou de plusieurs exercices : chaque société reçoit son propre SIREN fictif.
  4. Récupérez l'archive ZIP téléchargée par le navigateur, puis décompressez-la. Pour plusieurs fichiers, elle s'appelle cape-3f9a1c.zip.
Vous devez voirVos fichiers pseudonymisés et leur table de correspondance : table-3f9a1c.xlsx en clair, ou table-3f9a1c.map si vous avez choisi un mot de passe. 3f9a1c est la référence de la table : elle figure aussi dans le nom de chaque fichier pseudonymisé avec elle (rapport.cloak-3f9a1c.docx).
Table complétéeQuand vous complétez une table, l'archive en contient une nouvelle version, avec la même référence : elle remplace l'ancienne et couvre tous les fichiers, anciens et nouveaux. Conservez-la à la place de la précédente.
AttentionSans mot de passe, toute personne qui obtient la table peut lire les vraies valeurs : gardez-la sur votre poste. Si vous choisissez un mot de passe, notez-le en lieu sûr : sans lui, la table est illisible et personne ne peut la récupérer.
6

À chaque utilisation

Utiliser l'IA

L'IA travaille sur le fichier pseudonymisé : elle ne voit ni les noms, ni les numéros d'origine.

  1. Ouvrez le fichier pseudonymisé et relisez-le : c'est vous qui validez ce qui part.
  2. Envoyez les fichiers pseudonymisés à l'IA de votre choix. Avec une même table, une même valeur porte le même code dans tous les fichiers : l'IA peut les combiner.
  3. Enregistrez la réponse de l'IA dans un fichier : .docx, .xlsx, .txt, .csv ou .md.
AttentionN'envoyez jamais la table (.xlsx ou .map) à l'IA, et gardez-la sur votre poste.
7

À chaque utilisation

Rétablir les vraies valeurs

L'application remet les noms et les numéros d'origine à la place des codes, dans un fichier pseudonymisé comme dans la réponse de l'IA.

  1. Dans la partie « Rétablir les vraies valeurs », déposez le fichier à rétablir : un fichier pseudonymisé ou la réponse de l'IA.
  2. Déposez la table de correspondance, .xlsx ou .map : celle dont la référence figure dans le nom du fichier.
  3. Saisissez le mot de passe si la table est chiffrée (.map), puis cliquez sur Rétablir et télécharger.
Vous devez voirVotre navigateur télécharge le fichier avec les vraies valeurs. Un FEC que vous n'avez pas modifié retrouve son nom et son contenu d'origine, à l'identique.
Mauvaise tableSi le nom du fichier porte la référence d'une autre table, l'application le refuse : déposez la table dont la référence correspond. Les tables .map créées avec la version 0.1.0 restent lisibles.
